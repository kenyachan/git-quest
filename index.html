OLD COMMIT, THE SAGE

Welcome back, traveller. It's been a while since you last held a terminal. Your muscle memory has rusted, but it hasn't gone.

How to play:

  • Open a terminal (macOS/Linux Terminal, or Git Bash on Windows) and run each objective yourself. Type the commands out rather than pasting where you can, since typing is how you'll remember them.
  • Tick each objective when it's done. Clearing a level unlocks the next one.
  • Stuck? Open "What you should see" under each step.
  • Everything happens in a throwaway folder called git-quest. Nothing touches your real projects, and you don't need a GitHub account (Level 7 fakes a server on your own machine).

Your progress is saved in this browser.

New Game+ ideas:

  • Replay the whole quest tomorrow without opening the hints.

  • Try git bisect to hunt down which commit broke something.
  • Learn git cherry-pick and git worktree.
Tip: run git status whenever you're lost. It's the minimap of Git.
